# A town of agents, run twice: once through the gate, once without

**From the lab** · published 2026-11-25 · `gate` `agents`

> Ten agents ran a small town's economy for 48 days, twice. Through the gate nothing reached the fraudster, and what still got through showed which facts a rule must read.

We built a small town in code: a mill, a bakery, a cafe, a shop, a builder, a bank, a town hall, a tax office and twelve households. Ten model agents run it through tools, three of them briefed to profit by any means. We ran it twice from the same start, once with the gate deciding every action and once without. Without the gate the outside fraudster collected about 21,800 EUR; with it, nothing. What still got through, and the honest payments refused, taught the rule the whole gate is now built on: a rule reads the company's records, never a memory of its own, and a person's approval does not replace a missing rule.
