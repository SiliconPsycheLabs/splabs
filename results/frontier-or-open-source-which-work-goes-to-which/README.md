# Frontier or open source is the wrong question: which work goes to which model

**AI security and psychology** · published 2026-11-17 · `AI agents` `open models` `gate` `fine-tuning`

> A trillion-dollar model is the wrong tool for routine work, and a smarter model does not stop hidden instructions. What I read, what we tested, and where I draw the line.

In the week Anthropic lists above a trillion dollars and Mistral buys pages of the Financial Times to sell sovereign AI, the useful question is not which side wins. Hard problems go to a frontier model, routine work to a small model the company owns, and a fixed rule stands in front of every action of both.
